# צירים

מעקב צירים ללידה — משך, מרווח וכלל 5-1-1. הכל נשמר במכשיר, בלי חשבון ובלי שרת.

## הרצה

```bash
npm install
npm run dev
```

## מה בפנים

- שתי לחיצות לכל ציר: **התחיל** / **נגמר**
- עוצמה 1–5, ירידת מים, היסטוריה ושיתוף סיכום
- כלל 5-1-1 (לידה ראשונה) או 7-0.75-0.5 (לידה חוזרת)
- מסך דולק, רטט, מצב לילה, עברית מימין לשמאל

זה מעקב בלבד, לא ייעוץ רפואי.
